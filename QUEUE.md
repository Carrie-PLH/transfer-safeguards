# transfer-safeguards — jurisdiction queue

Build intent, not status; coverage truth lives in STATUS.md (generated by
tools/build-status.py). Work follows the charter's Build order.

**Exemplars (charter step 1) — done 2026-08-30:** the federal layer page
(federal.md / site/federal.html: 42 CFR 483.15, 42 CFR part 431 subpart E,
CMS SOM Appendix PP Rev. 232), Ohio as the hard shape (health department
hears the appeal, Medicaid rule publishes bed-hold, aging department
houses the ombudsman), and Texas as the simple shape (HHSC publishes
nearly everything).

**Baseline sprint order (charter step 2):** by certified-nursing-facility
resident population, computed 2026-08-30 by summing the "Average Number
of Residents per Day" column of the CMS Provider Data Catalog "Provider
Information" dataset (NH_ProviderInfo_Aug2026.csv, dataset modified
2026-08-01, data.cms.gov). Ordering data only — never evidence for any
page. Adjust freely when a reader or distributor gives a reason to jump a
state up.
